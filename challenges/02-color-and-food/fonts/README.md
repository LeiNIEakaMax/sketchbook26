# Fonts

The 9 fonts in the Font stepper (Figma frame "fonts", node 31:76071). All are self-hosted here.

- **LT Remark Regular**: Daniel Lyons (Lyons Type), https://lyonstype4.wixsite.com/lyonstype-beta/fonts. SIL OFL 1.1.
- **Handjet Regular**: Rosetta / David Březina, via Google Fonts (latin subset). SIL OFL 1.1.
- **Inconsolata Extra Condensed Bold** (wdth 62.5, wght 700): Raph Levien, via Google Fonts (latin subset). SIL OFL 1.1.
- **Manufacturing Consent Regular**: Fredrick Brennan, via Google Fonts (latin subset). SIL OFL 1.1.
- **Sprat Regular**: Collletttivo, https://www.collletttivo.it. SIL OFL 1.1 (`Sprat-LICENSE.txt`).
- **College**: Matthew Welch, http://www.squaregear.net/fonts/. Free to use and redistribute free of charge, with its licence text included unchanged (`College-LICENSE.txt`). Credit: College by Matthew Welch.
- **bianzhidai Base**: Xiaoyuan Gao / Not Your Type Foundry (notyourtype.nl). All rights reserved, and its licence doesn't allow copying it, so it is **not** in the repo. Put `bianzhidai-Base.otf` in `fonts/local/` (git-ignored) to use it on your own machine; elsewhere it shows as missing.
- **Velvelyne Regular**: Manon Van der Borght & Mariel Nils, Bye Bye Binary type library (https://genderfluid.space/). CUTE v0.1 (`Velvelyne-LICENSE.txt`): credit the designers, link the source, keep the licence with the files; donations are asked on a sliding scale.
- **CirrusCumulus**: Clara Sambot, https://gitlab.com/Clarasambot/cirruscumulus. SIL OFL 1.1 (`CirrusCumulus-LICENSE.txt`).
